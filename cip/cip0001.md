## Summary

Implement `read_gdocs` so `type: gdocs` returns one row per Google Doc
from Drive (optionally one folder or an extra query). Registration uses
lynguine's existing `google_oauth` credential kind. Read-only. Stdlib
HTTP against Drive v3 and the token endpoint; optional
`google-auth-oauthlib` only for interactive login.

**Which requirements does this CIP address?** REQ-0001.

## Motivation

Operators already keep work in Google Docs. lynguine can read Sheets via
core `type: gsheet`, and Trello/Maildir plugins show the CIP-0019 form.
Docs catalogue metadata belongs in a plugin package so Drive does not
grow another hard dependency chain in lynguine core.

CIP-0019 / CIP-0013 split Docs **body** to the document hook. This CIP
is only the catalogue table (like mail subjects, not MIME bodies).

## Detailed Description

### Layering

lynguine fetches the CIP-0005 secret named by `credential:` and injects
it as `details["credential_value"]`. This package never calls
`CredentialManager.get_credential`. The stored payload reuses
`google_oauth`:

```yaml
client_id: "..."
client_secret: "..."
refresh_token: "..."
token_uri: "https://oauth2.googleapis.com/token"  # optional
```

lynguine's built-in validator requires `client_id` and `client_secret`.
This reader additionally requires a non-empty `refresh_token`. Tokens
never appear in flow YAML and must not appear in exception messages.

### YAML

```yaml
plugins:
  - lynguine_gdocs

allocation:
  type: gdocs
  folder: FOLDER_ID
  index: id
  credential: my_google
```

| Key | Required | Meaning |
|-----|----------|---------|
| `credential` | yes | CIP-0005 key. lynguine binds `credential_value`. |
| `folder` | no | Drive folder **id**. Restricts with `'id' in parents`. |
| `query` | no | Extra Drive `q` clause, ANDed inside parentheses. |
| `limit` | no | Positive integer; stop after N Docs. |

Default Drive query:

```
mimeType = 'application/vnd.google-apps.document' and trashed = false
```

### Row grain

One row per Google Doc. Columns, in order:

| Column | Source |
|--------|--------|
| `id` | Drive file id |
| `name` | Title |
| `url` | `webViewLink` |
| `modified` | `modifiedTime` |
| `created` | `createdTime` |
| `owners` | Owner emails (else display names), `"; "` joined |
| `shared` | bool |
| `starred` | bool |

No body column.

### OAuth bootstrap

`python -m lynguine_gdocs.login` (oauth extra) runs an Installed-app
local-server consent and `set_credential(..., credential_type="google_oauth")`.
Default scope: `https://www.googleapis.com/auth/drive.readonly`.

If Google rotates the refresh token on refresh, attempt write-back via
`set_credential` (same pattern as maildir XOAUTH2).

### Out of scope

- Doc body / CIP-0013 reader
- Sheets (`type: gsheet` stays core)
- Write-back to Drive or Docs
- Service-account credentials (user-delegated refresh token first)
